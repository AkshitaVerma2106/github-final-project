# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Accepts principal amount as input.
- Accepts rate of interest as input.
- Accepts time period as input.
- Calculates and displays simple interest.
- Calculates the total amount (principal + simple interest).

## Technologies Used
- Bash
- Git
- GitHub

## How to Run
1. Open a terminal.
2. Navigate to the project directory.
3. Run the script using `bash simple-interest.sh`.
4. Enter the requested values.
